# 🔬 Science Quest 7

**Designed by Mr. Agurto 2026**

An interactive Grade 7 science study app: flip cards, quizzes, sorting games, matching games, a calculation lab, a 60-second Lightning Round, XP levels and 21 badges. Progress saves automatically in each student's browser.

## Units
1. 🔬 Scientific Method & Lab Skills: Inquiry, Design, Process, Evaluate, variables, Bunsen burner, graduated cylinder
2. ⚗️ Chemistry: matter, physical/chemical changes, atoms, Z and A, neutrons, ions, isotopes, isotones, isobars (+ Calc Lab)
3. ⚡ Physics: energy, KE, PE, work, transformations, machines, efficiency (+ Calc Lab, g = 10 N/kg)
4. 🧬 Living Things & Cell Theory: 4 supplies of life, 8 characteristics, cell theory, Janssen, Hooke, Van Leeuwenhoek, Schleiden, Schwann, Virchow
5. 🦠 Cells & Organelles: prokaryotes vs eukaryotes, organelles, plant vs animal cells
6. 🌍 Ecology & Biomes: biotic/abiotic, predation, herbivory, mutualism, parasitism, competition, biomes

## Publish on GitHub Pages
1. Sign in to github.com → **New repository** (e.g. `science-quest-7`), set it to **Public**, create it.
2. Click **Add file → Upload files**, drag in `index.html` (and this README), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After 1–2 minutes your link appears at the top of that page:
   `https://YOUR-USERNAME.github.io/science-quest-7/`

## Notes for the teacher
- Progress is stored per browser/device. Students can move it with the save code in **⚙️ Profile**.
- **📋 My Report** shows each student's progress and can be printed or saved as PDF to hand in.
- To add or edit questions, open `index.html` and edit the `UNITS` list at the top of the script. In each quiz question the **correct answer is written first**; the app shuffles the options.
